Stream API Reference Guide

✂️ Filtering & Slicing
filter Lazy
Keeps elements that match the predicate logic.
stream.filter(s -> s.length() > 3)
distinct Stateful
Removes duplicates based on equals().
stream.distinct()
limit Short-circuit
Truncates the stream to 'n' elements.
stream.limit(5)
skip Lazy
Discards the first 'n' elements.
stream.skip(2)
takeWhile Java 9
Takes elements until condition fails.
stream.takeWhile(n -> n < 10)
🔄 Mapping & Transforming
map Lazy
Applies a function to each element (1-to-1).
stream.map(String::toUpperCase)
mapToInt Primitive
Unboxes to IntStream (also mapToDouble).
stream.mapToInt(User::getAge)
flatMap Lazy
Flattens nested structures (1-to-Many).
stream.flatMap(List::stream)
📊 Sorting & Debugging
sorted Stateful
Sorts in natural order (Comparable).
stream.sorted()
peek Debug
Performs action without modifying stream.
stream.peek(System.out::println)
🔍 Finding & Matching
findFirst Optional
Returns first element (Deterministic).
stream.findFirst()
anyMatch Boolean
True if at least one element matches.
stream.anyMatch(s -> s.isEmpty())
allMatch Boolean
True if ALL elements match.
stream.allMatch(n -> n > 0)
📦 Reducing & Collecting
collect Mutable
Accumulate into List, Map, Set etc.
stream.collect(Collectors.toList())
reduce Immutable
Combine elements into single value.
stream.reduce(0, (a, b) -> a + b)
count Long
Returns number of elements.
stream.count()
🔄 Iterating
forEach Terminal
Runs action for each element.
stream.forEach(System.out::println)
🏭 Factories
Stream.of Create
Creates stream from explicit values.
Stream.of("A", "B", "C")
Stream.generate Infinite
Infinite stream from Supplier.
Stream.generate(Math::random)
